The portfolio

Each one is real DSP behind a straight face.

effect · dynamics

KPI Compressor

Compresses your dynamic range to meet quarterly targets.

Feed-forward, stereo-linked peak compressor: threshold, ratio, soft knee, attack, release, makeup, parallel mix, and a gain-reduction meter for the board.

effect · modulation

Stakeholder Chorus

More voices in the room, none of them listening.

Up to four modulated delay taps, each heard at a different phase on the left and the right. Mono goes in, a wider consensus comes out.

instrument · synth

Headcount

Scales headcount up to 8 voices and lays them off on note-off.

Two band-limited oscillators, a resonant zero-delay-feedback lowpass with an envelope sweep, ADSR, velocity, and oldest-first voice stealing during a hiring freeze.

effect · dynamics · sidechain

Executive Override

When the kick speaks, everyone else stops talking.

Ducks on a stereo sidechain bus, on the host's tempo (1/4, 1/8, 1/2, a bar), or on MIDI notes. Depth, attack, hold, release, curve, sidechain highpass, mix.

Install

Unzip the bundles into your VST3 folder, or build them yourself.

OSFolder
Linux~/.vst3
WindowsC:\Program Files\Common Files\VST3
macOS~/Library/Audio/Plug-Ins/VST3
git clone https://github.com/slopstack-labs/slaw-vsts
cd slaw-vsts
cargo test --workspace
cargo xtask bundle --release        # → target/bundles/*.vst3
slaw studio --plugin-folder target/bundles

In slaw: Settings → Plugins → Add folder…, or --plugin-folder, or VST3_PATH. Agents find them with the MCP list_plugins tool.

Governance

Unlike slaw, these plugins are fully deterministic. Legal insisted.

MIT all the way down

VST3 through the MIT vst3 crate. No GPL framework holding your source code hostage.

Zero-trust DSP

All unsafe lives in one substrate at the VST3 boundary. The plugins are pure functions of slices.

Real-time conduct

process() never allocates, locks, prints or blocks. Tests prove no NaNs, no denormals, and that each plugin does what its pitch says.
